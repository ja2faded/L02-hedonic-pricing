## Running the notebook

Use Python 3.10 or higher. Keep the `data` folder next to `notebook.ipynb`,
with `pierce_county_house_sales.csv` inside it. Open the notebook from this
folder and run the cells in order; it loads the CSV using
`data/pierce_county_house_sales.csv`, with no upload or personal path needed.
